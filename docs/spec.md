# 片刻 · Android 文本编辑器

## 已确认需求

- 美观、简单好用的中短文本编辑器，首个设计主题采用 Google Material 3。
- 支持主题切换，并有自然、流畅的动画。
- 每次主动启动编辑会话，自动载入系统剪贴板的最新文本。
- 提供系统下拉快捷设置磁贴，点击后直接编辑剪贴板。
- 右上角固定“完成”，点击后将完整编辑结果复制回系统剪贴板，并退出编辑器。
- 适配当前最新稳定 Android 17（API 37）。

## 第一版实现约定

- 应用名“片刻”，包名 `com.jackie.moment`，最低 Android 10（API 29），compile/target SDK 37。
- Kotlin、Jetpack Compose、Material 3。默认柔和蓝紫色，支持跟随系统 / 浅色 / 深色；可切换三种配色及 Android 12+ 壁纸动态配色。偏好保存在本机。
- 界面风格可在 Material、液态玻璃与毛玻璃间独立切换并保存，默认保留 Material。液态玻璃根据 Apple 官方设计原则制作 Android 实现：小型控制层呈现折射与高光，正文保留清晰的阅读面；API 33+ 使用 AGSL，较旧系统使用半透明填充与方向性细边。详细设计依据见 `docs/liquid-glass-design.md`。
- 液态玻璃与毛玻璃提供可选的“悬浮模式”，默认关闭，Android 11+ 显示开关。开启后由系统透明窗口直接透出启动前的界面，不捕获截图、不申请录屏或悬浮窗权限；系统支持时柔化背景，模糊不可用时提高阅读面的不透明度。Material 保持普通不透明窗口。切换保留文字、光标与会话内撤销记录。
- 个性化抽屉不显示“让片刻，更像你”或副文案，使用功能标题“个性化”，关闭按钮位于其右侧。可点击圆角选项的涟漪反馈必须裁切到与选项表面一致的圆角内。
- 三种主题统一采用编辑卡片和独立底部工具栏：卡片头部左侧为剪贴板状态、字符与行数，右上角为“完成”；不显示品牌图标、应用名称或副标题；中央可滚动正文；底部工具栏左侧撤销 / 重做，中间主题入口，右侧 A− / A+ 字号控件。主题与快捷设置说明放在底部抽屉。
- 窗口采用 edge-to-edge，适配键盘、系统手势区域、大屏及字体缩放；交互目标至少 48dp，图标有中文无障碍说明。
- 长文本编辑时，输入法展开或编辑视口变小时，自动保持当前光标所在行可见；保留插入点，手动浏览其他段落时不强制拉回。
- 主界面不显示底部“整理好……”提示；常规布局按窗口高度选择，输入法动画期间不切换紧凑装饰布局，避免编辑区域突然跳动。
- 在获得前台窗口焦点后读取剪贴板；从主题抽屉返回、收起通知栏、旋转和进程恢复不覆盖当前编辑。明确的桌面 / 快捷磁贴启动进入新会话。
- 不监控后台剪贴板。只读取文本，不把图片或内容 URI 转换为编辑内容。剪贴板为空时显示干净空白页和简短提示。
- “完成”保留所有换行、空白、emoji。先成功写入剪贴板，再结束任务；写入失败则保留界面并提示。系统返回不隐式复制。
- 磁贴标签“编辑剪贴板”，应用内提供“添加快捷开关”入口；Android 13+ 调用系统添加确认，Android 10–12 提示手动添加。系统确认由用户决定。
- 快捷开关添加卡片跟随系统磁贴生命周期：添加成功后整张隐藏，移除后恢复；页面已打开时也更新。通过系统监听恢复旧版已添加磁贴的状态，不因点击“添加”就认定已成功。
- 主界面底部各按钮独立响应按压；液态玻璃工具栏不因单个按钮按压产生整组压缩或联动反馈。
- 动画包括页面轻盈入场、按钮状态、主题颜色过渡、底部抽屉及完成收束；尊重系统动画缩放。
- 正式 APK 不申请网络、存储、悬浮窗或后台读取权限，不持久保存编辑文本。

- 毛玻璃为独立标准材质主题：API 31+ 对应用装饰背景使用原生局部模糊，正文更厚、工具栏较薄；前景文字保持锐利。悬浮时毛玻璃使用较强的系统背景模糊，模糊不可用时提高不透明度。详细依据见 `docs/frosted-glass-design.md`。

统一的圆角、布局、字号与设置控件规范见 `docs/ui-design-system.md`。

## 验收

1. Android 17 模拟器启动应用时，自动显示预先复制的中文、换行、emoji。
2. 修改后点击右上角“完成”，任务结束且剪贴板与编辑结果逐字相等。
3. 编辑期间失焦 / 回到前台 / 切换主题不覆盖文字；旋转后内容和光标保持。
4. 浅色、深色、系统模式及配色可切换，并在重启后保持。
5. 安装 / 添加系统磁贴后点击磁贴可以打开并自动载入最新文本。
6. 空剪贴板、非文本、空文本、长段落、emoji、键盘展开、大字体及宽屏无崩溃或控件遮挡。
7. 通过 debug/release 构建、单元测试、lint，以及关键功能的设备仪器测试；交付 APK 和运行截图。
