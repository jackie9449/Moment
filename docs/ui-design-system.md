# 片刻界面统一规范

目标：三种主题使用同一套布局、信息层级与控件形状，保留材质差异。主界面不加入品牌图标或营销标题。

## 布局与层级

- 主界面由同一张编辑卡片与独立底部工具栏组成。状态、字数、完成按钮统一收进编辑卡片页首；正文位于细分隔线下。悬浮模式不另加状态胶囊。
- 外侧边距 20dp，小窗口 16dp；卡片与工具栏相隔 12dp。编辑卡片圆角 28dp，工具栏 24dp，按钮和选项 16dp，设置容器 28dp。
- 所有操作目标至少 48dp。工具栏保持左右功能分组与居中主题入口；字号 A− / A+ 使用相同字重和基准字号。
- 完成在所有主题中使用同一强调色实心按钮，48dp 高，圆角 16dp；材质表现留给卡片与工具栏。
- 页首状态 12sp，字数 11sp；操作文字 14sp；设置标题 20sp；分组标签 12sp。正文保留用户所选的 14–26sp。

## 个性化

- 功能标题“个性化”＋关闭按钮，移除大幅营销卡片。
- 风格选项使用同规格的迷你页面预览，文字只保留主题名称。三种选中状态使用同一细边和勾选。
- 显示模式与主题配色使用相同的紧凑分段选择器；悬浮与壁纸开关使用相同的设置行。
- 快捷开关添加入口为紧凑功能行，保留系统已添加时隐藏的行为。
- 所有选项的触摸反馈裁剪在各自圆角内部；主工具栏每个按钮独立响应。
- 调色盘遮罩按抽屉实际露出高度连续变化：下滑逐渐恢复主界面，反向拖动逐渐恢复遮罩；松手、回弹、关闭按钮、空白处点击与返回键沿用相同位置进度，不再另启一条淡出动画。
- 点叉关闭使用 420ms 缓入缓出下滑，曲线 `(0.32, 0, 0.18, 1)`：轻缓起步、连续下移、柔和收尾，完全离开屏幕后再移除。背景遮罩与这段位移共享进度；短暂收起期间合并重复关闭操作。遵循系统动画时长设置。
- 侧滑返回的预览直接跟随系统手势进度，最多移动剩余距离的 24%；确认返回后从当前位置沿同一 420ms 曲线收起，取消则在 260ms 内柔和复位。返回键使用相同收起动作；面板自行处理其对话框窗口的返回，避免关闭主编辑页。

## 材质与行为

Material 为平整低饱和底色与清晰卡片；液态玻璃保留工具栏光学效果；毛玻璃保留原生背景柔化与较厚阅读层。正文、元信息与操作位置完全一致。设置使用一致的语义色与低强调选中底色。

保留剪贴板自动导入、完成精确复制并退出、文本和撤销历史、快捷开关状态、悬浮与兼容降级。常规布局尺寸不随输入法可见性切换；仅在极短窗口启用原有最小布局。

当前交付版本 0.1.15 / versionCode 16；最低 API 29，目标 API 37，无新增权限、依赖或后台行为。
