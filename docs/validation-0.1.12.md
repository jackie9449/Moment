# 片刻 0.1.12 · 液态玻璃提高通透度

普通阅读层不透明度从 94% 调为 78%。悬浮且系统模糊可用时，浅色从 78% 调为 64%，深色从 82% 调为 70%；背景透出比例分别为 36% 和 30%。模糊不可用时继续使用较厚阅读层。

悬浮工具栏的浅 / 深基准不透明度从 58% / 70% 调为 46% / 60%；普通光学材质均匀雾化从 11% / 16% 调为 4% / 7%。保留折射、方向高光和阴影。悬浮工具按钮增加薄局部底色，页首状态文字提高前景强度，适应更明显的背景。

- 9 项单元测试通过；debug / release / androidTest 构建成功。lint 0 errors、7 条既有 Warning。

- 正式签名包从 0.1.11 成功覆盖升级，保留液态玻璃、悬浮及浅色设置。用同一 60 字符文本和真实 Settings 背景检查普通 / 悬浮、浅色 / 深色。
