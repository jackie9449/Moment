# 片刻 0.1.9 · 液态玻璃材质重制

## 实现与依据

研究 Apple 官方材质、交互和自定义玻璃说明，以及 Android AGSL 的色彩、坐标与透明度要求；来源和实现边界见 `liquid-glass-design.md`。

重写光学模型：椭圆倒角法线、Snell 透射、角度相关的 Fresnel 反射、线性光照、双方向窄高光及轻微吸收。减轻宽白边、乳白覆盖和阴影，阅读层仍保持清晰。普通模式采样应用自己的背景；悬浮模式以预乘透明度和曲面反光叠加在系统合成的真实窗口上，不能折射其他应用的像素。

完成按钮与底部工具栏共用材质实现，按钮内部独立柔光和弹性反馈；Material 保留原有原生反馈。悬浮窗口模糊由 12dp 减至 6dp，减轻整体遮罩；页首状态卡片改为内容宽度。没有新增依赖或权限，没有持续动画循环。

versionCode 10，versionName 0.1.9，沿用原发布身份签名。
