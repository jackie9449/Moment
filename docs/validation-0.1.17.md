# 片刻 0.1.17 · 应用内语言选择

个性化 → 显示模式下方新增语言行，显示当前选择。菜单包含跟随系统、简体中文、繁體中文、English、日本語，并用勾标记选中项。原生语言名称不会随界面语言变化，方便切换回来。

## 实现

- API33+ 直接读写 LocaleManager.applicationLocales；系统应用语言和应用内入口共享选择，跟随系统清空该列表，不另外缓存一份可能失步的偏好。
- API29–32 保存 locale tag，在 Activity 基础 Context 应用 Configuration / LocaleList 并重建页面。系统默认时直接使用原 Context。磁贴每次开始监听时使用当前语言资源，避免驻留服务继续显示旧语言。
- 从旧系统升级后，旧偏好只迁移一次，不覆盖已经存在的系统应用语言。保存尚未完成的剪贴板导入标记，迁移触发首次重建也继续正确导入。
- 页面重建保留会话文本、选区、撤销 / 重做和个性化展开状态；切换语言不调用复制 / 完成，也不重新导入外部剪贴板。
- APK 保留所有语言资源，App Bundle 关闭语言分包，离线切换不依赖下载语言包。无新增权限或依赖。

接口依据：[Android 应用语言](https://developer.android.com/guide/topics/resources/app-languages)。

## 验证方法

语言映射单元检查覆盖存储 tag 回环、简繁脚本优先级、香港 / 台湾 / 澳门和英语 / 日语区域变体。

LanguagePickerTest 逐一通过实际菜单选择四种语言及跟随系统，每次检查草稿逐字保留、撤销回到原文 / 重做恢复草稿、重建后选择保持，并检查剪贴板没有因切换而被覆盖。另验证系统外部 zh-HK 选择反映到菜单、旧偏好迁移与首次剪贴板导入，以及旧版 Context 资源隔离 / 清除覆盖行为。

同时运行既有多语言、个性化手势及编辑重建回归。原始构建 / 单元 / lint / 设备日志、签名结果和原生截图位于 `artifacts/validation-0.1.17/`。
