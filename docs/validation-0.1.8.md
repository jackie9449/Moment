# 片刻 0.1.8 · 液态玻璃悬浮模式

## 实现

- 液态玻璃设置下新增“悬浮模式”，默认关闭，在 Android 11 / API 30 及以上显示；Material 始终使用普通不透明窗口。
- 通过透明主题及公开的 Activity.setTranslucent 更新系统窗口遮挡状态，直接透出当前窗口后面的实际界面。没有录屏、截图、辅助功能服务或 SYSTEM_ALERT_WINDOW 权限。
- Android 12+ 监听系统跨窗口模糊能力，启用适度的 blur-behind；系统不支持或关闭模糊时，提高阅读面的不透明度，保持输入文字清晰。前景文字不参与模糊。
- 悬浮模式停用覆盖背景的自绘色场与不透明折射着色器，保留透明材质填充、边缘高光、独立按钮反馈；补强系统栏及深色工具栏的对比度。
- 切换窗口模式通过正常的 Activity 重建完成，保存文字、光标及设置抽屉状态；EditorSessionModel 在内存中保留撤销 / 重做，进程恢复仍只序列化当前文字和选区，避免将历史文本塞入保存状态。
- versionCode 9，versionName 0.1.8，沿用原有发布签名。

## 验证

- 9 项单元测试通过，包括新增的窗口重建保留撤销历史、进程恢复保留文字 / 选区两项。
- debug / release 构建成功，lint 0 errors、7 条既有提示，签名和对齐校验通过。
- Android 17 / API 37 Pixel 9 模拟器完整设备回归 12 项通过，耗时 49.802 秒；其中新增两项悬浮回归使用独立任务中的彩色真实窗口，通过实际合成截图的边缘像素差异验证背景透出。
- 新回归同时检查：开启 / 关闭与 Material 切换、偏好保存、重建、文字与撤销保留、完成时精确复制并返回原任务，以及系统禁用模糊时的兼容行为。关闭设置后等待实际屏幕合成帧，避免把尚未消失的设置窗口误作背景。
- 开启系统动画后，悬浮模式下的键盘几何稳定、文末与中间光标避让 3 项专项通过，耗时 18.773 秒。
- 正式包安装后，通过实际快捷开关从 Android 系统设置启动编辑器，检查浅色、深色、输入法展开状态。点击完成后，活动任务确实返回 SettingsHomepageActivity，记录为 `return-to-previous.txt`。
- 最后的颜色调整重新构建、执行单元测试与 lint，并用正式包复核深浅主题，修正透明根容器默认内容色导致的深色工具图标对比度问题。
