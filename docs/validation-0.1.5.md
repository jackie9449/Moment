# 片刻 0.1.5 · 液态玻璃主题

## 实现

- 新增界面风格 Material / 液态玻璃，独立保存于显示模式、配色与字号之外，旧用户升级后默认保留 Material。
- 依据 Apple 官方设计原则制作 Android 玻璃控制层：自绘背景色场、圆角边缘折射、柔和散射表现、方向性高光、按压亮度与弹性反馈；正文为高不透明度的阅读面。
- API 33+ 使用记忆化的 RuntimeShader / ShaderBrush；API 29–32 使用渐变、高光与阴影的兼容路径。没有新依赖、权限或无限动画循环，不捕获或模糊用户文字。
- 键盘只改变视口，材质绘制不改变控件测量。明暗切换与玻璃光线用 320ms 过渡，交互弹性遵循系统动画缩放。
- 设计研究和来源见 `docs/liquid-glass-design.md`。这是安卓自有实现，不等同于 Apple 系统渲染器。

## 验证

- debug / release 构建成功；单元测试 7 项通过；lint 0 errors、7 条既有警告。
- 完整设备套件 9 项通过，耗时 39.797 秒。新增回归检查液态玻璃切换、重建后的偏好保存、编辑文字保留及复制结果逐字相等。
- 开启系统动画，液态玻璃专项 4 项通过，耗时 29.649 秒：大字体 / 小窗口、键盘前后编辑区几何稳定、文末光标避让、中间光标继续输入与自由滚动。
- 开启系统动画后，风格切换 / 重建 / 复制回归再验证通过，耗时 14.132 秒。
- 正式签名包重新安装，人工检查玻璃浅色、深色与真实输入法展开状态，以及设置中的风格入口。
- 实际运行设备为 Android 17 / API 37 Pixel 9 模拟器。尚未在厂商手机及 API 29–32 设备验证兼容绘制路径，没有做真机帧率或功耗测量。
