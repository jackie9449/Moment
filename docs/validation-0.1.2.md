# 片刻 0.1.2 · 长文本光标避让

## 修改

- 使用文本框自身的焦点交互状态判断真实编辑焦点。
- 在输入法展开、编辑视口高度或光标位置改变后，根据当前光标矩形调整滚动距离。旧布局与新文本不一致时等待新布局，避免使用过期位置。
- 只滚动到当前插入点需要的位置，保留中间段落的光标，不强制跳到文末；手动滚动偏移不作为自动定位的触发条件。
- 保留 0.1.1 的简洁顶部布局。versionCode 3，versionName 0.1.2。

## 复现与验证

Android 17 / API 37 Pixel 9 模拟器中，用 60 行文本关闭并重新展开真实输入法，修复前中间光标底边相对视口为 1337px，而视口高度仅 851px；文末也能复现遮挡。

新增两项设备回归，检查实际文字布局、滚动偏移与可见编辑区：

1. 文末光标：重新展开输入法后，光标完整处于可见区域。
2. 第 35 行附近光标：重新展开后插入位置不变；继续输入换行和 emoji 后仍可见；手动滚动浏览不会被自动拉回。

新增回归在启用系统输入法动画时单独通过。完整设备套件（原有 5 项 + 新增 2 项）全部通过，耗时 126.428 秒。单元测试 7 项通过，lint 0 errors、7 条既有信息性警告；debug/release 构建与签名验证通过。
