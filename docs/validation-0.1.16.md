# 片刻 0.1.16 · 完成退出与多语言

## 行为

- 主编辑页返回与完成共用一个防重复的复制 / 退出入口，保留首尾空格、换行及 emoji。系统 IME 可以先消费返回以收起键盘；个性化面板的返回仍只收起面板。
- 修改过的会话在主动 Home / 上滑 / 切换应用时通过 onUserLeaveHint 同步写入剪贴板并移除任务；未修改时不覆盖其他来源的新剪贴板。不在 onPause 或失焦时复制，锁屏 / 非用户发起的中断保留会话。添加磁贴的系统请求期间抑制自动完成。
- 原始会话基线及脏状态只进入 Android 临时恢复状态；重建后继续正确判断是否修改。窗口焦点变化不重新导入。
- 完成和主界面返回：360ms 缓入缓出、3% 缩小、20dp 下移及淡出，API30+ 用公开 setTranslucent 透出前一界面，动画结束再移除任务；失败时回退直接完成。API29 使用原生淡出 / 位移动画。Home 的回桌面动画由系统桌面负责，应用不接管或拦截该系统手势。
- 新增 en、zh-Hant（含台湾与香港）、ja 的全部 45 条界面 / 辅助功能 / 消息文案。跟随系统语言，API33+ 通过 localeConfig 支持系统应用语言选择；低版本仍用资源匹配。
