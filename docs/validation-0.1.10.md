# 片刻 0.1.10 · 毛玻璃主题与悬浮模式

## 实现

研究 Apple 官方标准材质、UIBlurEffect、Vibrancy 与厚度 / 可读性分层，设计依据和链接见 `frosted-glass-design.md`。

新增独立“毛玻璃 / 柔雾 · 沉静”，与 Material、液态玻璃并列。采用漫射色场、原生背景模糊、半透明中性色层、细边与轻阴影；前景文字保持清晰。正文较厚，工具栏较薄。明暗切换 320ms 过渡，按钮保持独立柔光和弹性反馈。

普通模式仅将装饰背景记录为 GraphicsLayer，对带 54dp 边距的局部裁剪使用 18dp BlurEffect；正文和控件不进入被模糊的图层。Android 10–11 使用高不透明度兼容表现。没有截图位图，没有持续运行的动画循环。

毛玻璃同样支持 Android 11+ 悬浮模式，默认关闭；与液态玻璃共用开关。系统支持跨窗口模糊时使用 20dp，液态玻璃保留 6dp；在两种玻璃间切换时原位更新模糊强度。系统关闭模糊时提高不透明度。文字、光标与撤销历史保持，Material 仍为普通不透明窗口。

versionCode 11 / versionName 0.1.10，沿用原有发布签名；无新增依赖和权限。
